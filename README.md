# 웹툰 배경 3D

3D 모델을 불러와 배치하고, 인물 눈높이로 컷 구도를 잡아 이미지로 내보내는 브라우저 툴.
전체 계획과 파일 구조는 [PLAN.md](PLAN.md) 참고.

## 실행

1. [Node.js](https://nodejs.org) LTS 버전 설치 (처음 한 번)
2. 실행
   - **Windows**: `start-windows.bat` 더블클릭
   - **Mac**: `start-mac.command` 더블클릭 (막히면 우클릭 → 열기)
   - 또는 이 폴더에서 터미널을 열고:
     ```
     npm install     ← 처음 한 번 + 업데이트 받은 뒤에 한 번
     npm run dev
     ```
3. 브라우저가 자동으로 열립니다. 안 열리면 http://localhost:5173 접속.
4. 끝낼 때는 터미널 창에서 `Ctrl + C` (또는 창 닫기).

코드를 고치고 저장하면 브라우저에 바로 반영됩니다.

## 사용법 (1단계: 배치)

| 하고 싶은 것 | 방법 |
|---|---|
| 모델 불러오기 | GLB / GLTF / OBJ / SKP(SketchUp) 파일(폴더, ZIP 도 됨)을 화면에 끌어다 놓기, 또는 `모델 불러오기…` |
| 시점 돌리기 / 이동 / 확대 | 왼쪽 드래그 / 오른쪽 드래그 / 마우스 휠 |
| 모델 선택 | 클릭 (빈 곳 클릭 또는 `Esc` 로 해제) |
| 이동 / 회전 / 크기 핸들 | `W` / `E` / `R` 또는 패널 버튼 |
| 복제 / 삭제 | `Ctrl+D` / `Delete` |
| 높이 맞추기 | 패널 `높이` 칸에 m 단위 숫자 입력 후 Enter (비율 유지) |
| 선택한 모델로 시점 이동 | `F` |
| 사람 모형 놓기 | `사람 배치` → 바닥이나 모델 윗면 클릭 (누른 채 드래그하면 그 방향을 봄) |
| 사람 체형 · 키 | `사람` 칸의 남성 / 여성, 키 버튼 또는 직접 입력 (선택한 사람 / 새로 놓을 사람) |
| 사람 모형 숨기기 | `보기` → `사람 모형 보이기` 끄기 |

## 사용법 (사람 포즈)

| 하고 싶은 것 | 방법 |
|---|---|
| 포즈 모드 | 사람을 더블클릭, 또는 사람 선택 후 `사람` 칸 `포즈 모드` |
| 관절 돌리기 | 포즈 모드에서 관절 점(또는 팔·다리 등 몸 부위) 클릭 → 회전 핸들 드래그 (하위 관절이 따라감) |
| 관절 해제 / 포즈 모드 끝 | `Esc` 한 번 / 한 번 더 (관절을 안 고른 동안은 사람 전체 이동·회전) |
| 포즈 프리셋 | 서기 · 이동 · 앉기·눕기 · 동작 분류로 33가지 (대화, 전화, 난간에 기대기, 운전, 쪼그려 앉기, 눕기, 줍기, 마시기 등). 선택한 사람에게 바로 적용 |
| 손 모양 | `손 모양` 에서 양손 / 왼손 / 오른손 고른 뒤 편하게 · 펴기 · 쥐기 · 주먹 · 가리키기 · 브이 · 엄지 척 · OK |
| 포즈 초기화 / 복사 / 붙여넣기 | `초기화` / `포즈 복사` → 다른 사람 선택 → `붙여넣기` |

무릎·팔꿈치가 반대로 꺾이지 않는 등 사람이 움직일 수 있는 범위 안에서만 돌아가고, 발은 자동으로 바닥에 붙습니다.

## 사용법 (모델 안의 부품 · 레이어)

| 하고 싶은 것 | 방법 |
|---|---|
| 모델 안으로 들어가기 | 모델 더블클릭 (더 안쪽 그룹도 더블클릭으로 계속) |
| 부품 선택·이동·회전·복제·삭제 | 들어간 상태에서 클릭 → 핸들, `Ctrl+D`, `Delete` |
| 한 단계 위로 | `Esc` (들어갔던 그룹이 선택됨) |
| 구조 보기 | 왼쪽 `레이어` 패널: ▸ 펼치기, 이름 클릭 = 선택, 이름 더블클릭 = 들어가기 |
| 숨기기 | 레이어 패널의 눈 아이콘 (화면·내보내기·그림자에서 빠짐) |
| 잠그기 | 자물쇠 아이콘 (클릭해도 선택 안 됨, 1인칭에서는 그대로 밟힘) |

## 사용법 (2단계: 인물 시점)

| 하고 싶은 것 | 방법 |
|---|---|
| 1인칭 모드 들어가기 / 나가기 | 패널 `1인칭 모드 시작` (지금 보는 자리에서) / `Esc` |
| 원하는 곳에 서서 시작 | `시작 위치 찍기` → 바닥이나 모델 윗면 클릭 (누른 채 드래그하면 그 방향을 봄) |
| 고개 돌리기 | 화면을 누른 채 드래그 |
| 걷기 | `W` `A` `S` `D` (또는 방향키), `Shift` 누르면 빠르게 |
| 눈높이 | 패널 버튼(아이·성인·앉은 키·로우앵글) 또는 직접 입력, `Q` / `E` 로 조금씩 |
| 계단·경사 오르내리기 | `지형 따라가기` 켜기 (0.4m 넘는 건 벽처럼 막힘). 끄면 높이 고정·벽 통과 |
| 고개 수평 (세로선 똑바로) | 패널 `고개 수평으로` |
| 화각 | 패널 24 / 35 / 50mm 또는 직접 입력 |

## 사용법 (3단계: 컷 잡기 + 내보내기)

| 하고 싶은 것 | 방법 |
|---|---|
| 컷 비율 | `컷 프레임` 칸: 세로형 3:4 / 가로형 4:3 / 정사각 또는 직접 입력 |
| 3분할 격자 · 눈높이선 | `컷 프레임` 칸 체크박스 |
| PNG 저장 | `내보내기` 칸: 가로 픽셀 입력 → 일반 렌더 / 선화 / 그림자만 선택 → `PNG로 내보내기` (프레임 안쪽만) |
| 일반 렌더에 선 | `외곽선·모서리선 그리기` 켜기 → 선 두께(화면 기준)·모서리 각도. 화면에 바로 보이고, 가로 픽셀을 키워도 같은 비율로 나옴 |
| 선화 조절 | 선 두께(결과 이미지 px), 모서리 각도(작을수록 선이 많아짐) |
| 그림자 레이어 | `그림자만`: 흰 바탕에 회색 그림자 → 그림 프로그램에서 곱하기 레이어로 |
| 사람 빼고 저장 | `사람 모형 포함` 끄기 |

## 사용법 (저장 · 컷 목록)

| 하고 싶은 것 | 방법 |
|---|---|
| 프로젝트 저장 | `파일` 칸 `저장` 또는 `Ctrl+S` → `.webtoon3d` 파일 하나 (모델 파일까지 들어 있어 그 파일만 옮기면 다른 컴퓨터에서도 열림) |
| 같은 파일에 덮어쓰기 | 크롬·엣지는 처음 저장한 뒤로 `Ctrl+S` 가 같은 파일에 덮어씀. 다른 이름으로: `Ctrl+Shift+S` |
| 프로젝트 열기 | `열기…` 또는 `.webtoon3d` 파일을 화면에 끌어다 놓기 |
| 실수로 창을 닫았을 때 | 다시 열면 위쪽에 '자동 저장된 작업이 있어요 → 복구' |
| 컷 저장 | `컷 목록` 칸 `지금 시점을 컷으로 저장` (시점·화각·컷 비율·해 방향) |
| 컷으로 돌아가기 | 목록에서 컷 누르기. ⟳ 지금 상태로 바꾸기 · ✎(또는 이름 더블클릭) 이름 · ✕ 지우기 |

## 사용법 (그림자)

| 하고 싶은 것 | 방법 |
|---|---|
| 그림자 켜기 | `그림자` 칸 `그림자 켜기` |
| 해 방향 | `해 방위` (0° 북 · 90° 동 · 180° 남 · 270° 서), `해 높이` (0° 지평선 ~ 90° 머리 위) |
| 그림자 농도 / 경계 | `진하기`, `부드러움` |
| 큰 맵에서 느릴 때 | `품질` → 낮음 (화면에서 보이는 곳 중 가까운 거리까지만 그림자를 계산). 내보낼 때는 품질 설정과 상관없이 최고 품질 |
| 구석 어둡게 (AO) | `구석 어둡게 (AO)` 켜기 → 세기. `'그림자만' 내보내기에 포함` 으로 그림자 레이어에 넣을지 선택 |

단위는 미터입니다 (바닥 격자 1칸 = 1m, 진한 선 = 10m).

## SKP(SketchUp) 파일

- `.skp` 파일 하나만 넣으면 됩니다 (재질·텍스처가 파일 안에 있음). SketchUp 2013 ~ 최신 버전 파일.
- SketchUp 의 그룹·컴포넌트가 레이어 패널에 그대로 나오고, 더블클릭으로 안에 들어가 부품을 옮길 수 있습니다.
- SketchUp 에서 숨긴 물체·숨긴 태그는 숨긴 채로 들어옵니다 (레이어 패널 눈 아이콘으로 보이기).
- 칠하지 않은 면은 밝은 회색. TIFF·BMP 텍스처는 평균 색으로 나옵니다.
- 일부 파일은 못 읽거나 빠지는 부분이 있을 수 있어요 (SketchUp 공식 읽기 도구가 아니라서). 그럴 때는 SketchUp 에서
  `파일 → 내보내기 → 3D 모델` 에서 **OBJ** 로 내보내서 불러오세요.
