# 웹툰 배경 3D

3D 모델을 불러와 배치하고, 인물 눈높이로 컷 구도를 잡아 이미지로 내보내는 브라우저 툴.
전체 계획과 파일 구조는 [PLAN.md](PLAN.md) 참고.

## 실행

1. [Node.js](https://nodejs.org) LTS 버전 설치 (처음 한 번)
2. 실행
   - **Windows**: `start-windows.bat` 더블클릭
   - **Mac**: `start-mac.command` 더블클릭 (막히면 우클릭 → 열기)
   - 또는 이 폴더에서 터미널을 열고:
     ```
     npm install     ← 처음 한 번만
     npm run dev
     ```
3. 브라우저가 자동으로 열립니다. 안 열리면 http://localhost:5173 접속.
4. 끝낼 때는 터미널 창에서 `Ctrl + C` (또는 창 닫기).

코드를 고치고 저장하면 브라우저에 바로 반영됩니다.

## 사용법 (1단계)

| 하고 싶은 것 | 방법 |
|---|---|
| 모델 불러오기 | GLB / GLTF / OBJ 파일(폴더, ZIP 도 됨)을 화면에 끌어다 놓기, 또는 `모델 불러오기…` |
| 시점 돌리기 / 이동 / 확대 | 왼쪽 드래그 / 오른쪽 드래그 / 마우스 휠 |
| 모델 선택 | 클릭 (빈 곳 클릭 또는 `Esc` 로 해제) |
| 이동 / 회전 / 크기 핸들 | `W` / `E` / `R` 또는 패널 버튼 |
| 복제 / 삭제 | `Ctrl+D` / `Delete` |
| 높이 맞추기 | 패널 `높이` 칸에 m 단위 숫자 입력 후 Enter (비율 유지) |
| 선택한 모델로 시점 이동 | `F` |
| 크기 비교용 사람(1.7m) | 패널 `사람 모형` 체크 |

단위는 미터입니다 (바닥 격자 1칸 = 1m, 진한 선 = 10m).
