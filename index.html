웹툰 배경 3D

파일

GLTF·OBJ는 .bin/.mtl/텍스처를 함께 선택하거나 폴더째 끌어다 놓으세요.

인물 시점

찍기: 바닥·모델 윗면 클릭 → 그 위에 서기 (누른 채 드래그 → 바라볼 방향)

켜면 계단·경사로를 오르내리고(0.4m 까지), 더 높은 건 벽처럼 막힘. 끄면 높이 고정·벽 통과.

눈높이

1인칭 모드에서 Q / E 로 조금씩 낮게 / 높게 (발밑 기준)

화각 (렌즈)

숫자가 작을수록 넓게, 클수록 좁게 보입니다.

사람

바닥·모델 윗면 클릭 → 그 위에 세우기 (누른 채 드래그 → 바라볼 방향)

키 (새로 놓을 사람)

포즈

사람을 고른 뒤 누르거나, 사람을 더블클릭하세요.

편집 핸들
선택한 모델

모델이나 사람을 클릭하면 선택됩니다.

숫자를 넣고 Enter → 비율 유지하며 크기 맞춤

그림자

방위 0° 북(-Z) · 90° 동(+X) · 180° 남 · 270° 서. 높이 0° 지평선 ~ 90° 머리 위.

품질

컷 프레임

화각(mm)은 프레임의 긴 변 기준입니다.

내보내기 (PNG)

흰 바탕에 그림자만 회색으로 — 곱하기 레이어로 겹쳐 쓰세요. 회색 농도 = 그림자 진하기. 그림자를 꺼 두어도 계산합니다.

두께는 화면에 보이는 굵기 기준 — 가로 픽셀을 키워도 화면에서 본 비율 그대로 나옵니다.

흰 면 + 검은 선, 배경 투명. 두께는 결과 이미지 px. 각도가 작을수록 모서리 선이 많아집니다.

프레임 안쪽만 저장됩니다 (그리드·핸들·선 표시는 빠짐).
